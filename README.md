### 👋 Hi, I'm @denismapa

**Senior Information Security Compliance Engineer** at a "Warehouse Retailer"

I started out as a network engineer for a large enterprise and moved into security compliance, so I approach PCI DSS from the wire up. Today I scope cardholder data environments, validate network security controls and segmentation, and build automation that takes the pain out of evidence collection. At home, I keep my networking hands-on with a segmented UniFi and Proxmox homelab.

---

#### Networking background

- **Enterprise network engineering**: former Network Engineer for a large enterprise, which is the foundation for everything I do in security
- **Segmentation & scoping**: using network segmentation to define and reduce PCI DSS scope, then validating that it holds
- **Network security controls**: reviewing firewall and router rule sets against business justification (PCI DSS Requirement 1)
- **Privileged access**: auditing the Active Directory groups that grant admin access to firewalls, routers and other infrastructure
- **Service & port discovery**: PowerShell and Bash tooling that maps listening ports to the services that own them on Windows and Linux servers

#### Security & compliance

- **PCI DSS assessment**: scoping, control validation, evidence collection and assessment readiness
- **Identity & access**: Active Directory and PingFederate authentication
- **Automation**: scripting the repetitive parts of audits with PowerShell, Python and Google Sheets

#### Homelab & side projects

- **UniFi network** segmented into VLANs by trust zone (core, services, guest)
- **Proxmox VE** hosts running VMs and LXC containers, plus an Unraid server for storage
- **Cloudflare Tunnel** to publish self-hosted apps like Nextcloud without opening any inbound ports
- **Pi-hole** for network-wide DNS filtering, moving to a highly available pair
- **Next up**: a Proxmox + TrueNAS build on ZFS with 10GbE
- Building side projects with AI as my pair programmer
